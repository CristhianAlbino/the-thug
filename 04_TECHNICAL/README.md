**C++**: foundations, reusable systems, performance-sensitive logic.

**Blueprint**: composition, tuning, content implementation and rapid iteration.

Initial Unreal systems expected:
- Enhanced Input
- AI Perception
- Behavior Trees / State Logic
- Navigation
- Gameplay components
- Data Assets / Data Tables
- MetaSounds
- Level streaming / World Partition where appropriate
- Save / Load

The first goal is a functional prototype, not final graphics.
