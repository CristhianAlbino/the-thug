# UnrealProject

This directory is reserved for the Unreal Engine project.

## Day 1

Create the Unreal Engine 5 project here and keep:
- Config/
- Content/
- Source/
- Plugins/
- Scripts or project tooling when applicable
- TheThug.uproject

Do **not** commit generated folders such as:
- Binaries/
- DerivedDataCache/
- Intermediate/
- Saved/

Before adding binary Unreal assets locally, ensure **Git LFS is installed and enabled**.
