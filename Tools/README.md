# Tools

Engine-independent C++17 systems and test tooling:

- [HunterCore](HunterCore/README.md) — Hunter perception/memory decisions and campaign route/finale rules, with standalone tests.

- [CompanionCore](CompanionCore/README.md) — independent companion state and conditional goals, with standalone tests.

- [SurvivalCore](SurvivalCore/README.md) — injuries, stamina, bleeding and inventory rules, with standalone tests.

- [PerceptionCore](PerceptionCore/README.md) — uncertain sound and observed environmental evidence, with standalone tests.

- [CampaignCore](CampaignCore/README.md) — shared campaign clock/pause, authored initial profiles, atomic interactions, native keypad and narrative commands, runtime checkpoint receipts and validated disk writes/recovery.

- [DirectorCore](DirectorCore/README.md) — conditional pt-BR text, scene/banter priorities, confirmed cues, journal and epilogues; parity with the Python reference. Physical presentation remains an engine responsibility.

Other developer utilities can be added here as needed.
