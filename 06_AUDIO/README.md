# 06_AUDIO

Audio design is a core gameplay system in **The Thug**.

Ordem do autor atualizada em 07/10/2026: **assets/modelos/texturas/rig/animações antes; vozes no último lote antes da Unreal**. Nenhuma voz foi gerada no kit 3D v01.

Planned areas:
- Music
- SFX
- Ambience
- Foley
- Voice
- Dialogue
- MetaSounds
- Sound Classes
- Sound Mixes
- Reverb
- Audio Data

Core principle:
> The player should sometimes survive because they heard something before they saw it.

Adaptive states:
- Exploration
- Tension
- Investigation
- Hunter Near
- Pursuit
- Hiding
- Recovery

O [catálogo de produção](../Tools/ProductionCore/README.md) indexa cues/variantes e requisitos de som/música/AUD. A [preparação de produção](../01_PROJECT/Roadmap/PLANO_PRODUCAO_PRE_UNREAL_V1.md) define masters, takes e avaliação. Gravações finais ainda não foram produzidas.
