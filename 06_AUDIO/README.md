# 06_AUDIO

Audio design is a core gameplay system in **The Thug**.

Planned areas:
- Music
- SFX
- Ambience
- Foley
- Voice
- Dialogue
- MetaSounds
- Sound Classes
- Sound Mixes
- Reverb
- Audio Data

Core principle:
> The player should sometimes survive because they heard something before they saw it.

Adaptive states:
- Exploration
- Tension
- Investigation
- Hunter Near
- Pursuit
- Hiding
- Recovery
